# ARENA NOW — 디자인 비전 (개발 보류, 기획 보존)

> 이 문서는 서울아레나 제휴가 구체화된 뒤 착수할 ARENA NOW의 전체 스펙입니다.
> SHOWDAY 1.0 개발 우선순위 결정에 따라 지금은 `/arena`를 "준비 중" 프리뷰
> 수준으로만 두고, 아래 내용은 구현하지 않습니다. 착수 시점이 오면 이 문서를
> 기준으로 SHOWDAY와는 별도의 UI/UX로 새로 설계합니다.

## 포지션
- SHOWDAY = 전국 공연 발견·추천 플랫폼 (화이트 기반, 대중적 UI)
- ARENA NOW = 서울아레나 현장 경험에 특화된 SHOWDAY의 독립형 서비스
  (Dark / Black / Glass / Full Screen / Motion)
- URL은 `showday.kr/arena`로 유지하되, 화면은 완전히 다른 서비스처럼 디자인

## 1. 첫 화면 — 조감도가 곧 인터페이스
- 서울아레나 대형 조감도를 화면 전체 배경으로 사용 (메뉴 박스 나열 X)
- 카피: "ARENA NOW / THE SHOW STARTS BEFORE THE SHOW. / 공연은 공연장에
  들어가기 전부터 시작됩니다."
- 하단에 상황별로 바뀌는 버튼 하나만:
  - 평소: "오늘 공연 보기 →"
  - 공연 당일: "D-DAY · 19:00 / 오늘 서울아레나에 가시나요? / MY SHOW DAY 시작하기"
- **주의**: 조감도를 실제 배경으로 쓰려면 이미지 이용권한 확인 필수.
  프로토타입은 공식 자료 참고, 운영용은 사용 허가 이미지/자체 제작 비주얼로 교체.

## 2. 조감도 = 살아있는 지도
조감도 위에 포인트 배치, 클릭 시 카드가 열림 (사진 + 지도 + 공연정보 + 시간표 통합):
- ARENA — 오늘 공연
- EAT — 공연 전 식사
- PARENTS TIME — 부모의 3시간
- PICKUP — 예약·픽업
- AROUND — 창동 둘러보기
- HOME — 공연 후 귀가

## 3. 핵심 자산 — "시간" 중심 설계 (MY SHOW DAY)
장소 추천이 아니라 공연시간 기준으로 하루 전체를 자동 설계.
예시 타임라인:
```
15:30 창동 도착 → 16:00 식사 → 17:20 카페 → 18:00 굿즈/짐보관
→ 19:00 SHOW → 21:30 공연 종료 → 21:45 야식 → 22:40 귀가
```

## 4. 3 HOURS (부모 프로그램, 별도 브랜드급)
"아이가 공연을 보는 3시간, 부모에게도 새로운 공연이 시작됩니다."
- FOR PARENTS: 강연 / AI 클래스 / 명상 / 음악 / 소극장 공연 / 건강 / 문화체험 / 식사
- 공연시간에 맞춘 코스 예시:
  ```
  자녀 공연 19:00–21:30
  18:50 체크인 → 19:10 토크 → 20:10 Tea Break
  → 20:30 음악 프로그램 → 21:20 아레나 이동
  ```
- 향후 도봉구 제안사업의 대표 콘텐츠 후보

## 5. 공연 당일 상태머신 — 화면이 시간에 따라 변함
평상시 `NEXT SHOW D-12` → 전날 `TOMORROW` → 당일 `🔴 LIVE DAY` →
3시간 전 `3 HOURS TO SHOW` → 30분 전 `DOORS OPEN` → 공연 중 `ON STAGE` →
종료 후 `AFTER SHOW`. 각 상태마다 노출 정보가 자동으로 바뀜.

## 6. SHOW ENDED 화면
공연 종료 시점에 완전히 다른 화면으로 전환:
"오늘의 공연은 끝났지만 당신의 SHOW DAY는 아직 끝나지 않았습니다."
→ 막차까지 남은 시간, 지금 갈 수 있는 곳, 택시, 주차장, 숙박, AFTER SHOW FOOD

## 7. AROUND — 상황 기반 분류 (지도앱과의 차별점)
일반 맛집 리스트가 아니라 관람객 상황으로 분류:
- NOW OPEN (지금 영업 중)
- 60 MINUTES (공연 전 1시간 안에 가능)
- AFTER 10PM (밤 10시 이후 가능)
- 10 MIN WALK (걸어서 10분)
- PARENTS PICK (부모님 추천)

## 8. SHOWDAY와의 연결 방식
SHOWDAY(발견→관심등록→알림→예매) 흐름 중, 서울아레나 공연이면:
"이 공연은 ARENA NOW를 지원합니다. 공연 가는 하루를 준비할까요?
MY SHOW DAY 만들기 →" 로 전환. 두 서비스를 한 화면에 억지로 섞지 않음.

## 9. 장기 확장 — 공연장별 O2O 플랫폼
서울아레나에서 모델 검증 후:
`ARENA NOW · SEOUL ARENA` → `ARENA NOW · GOCHEOK` → `ARENA NOW · KSPO` →
`ARENA NOW · INSPIRE` 로 확장. 이후 공연장/지자체 대상
"ARENA NOW powered by SHOWDAY" B2B 제안 가능.

## 착수 조건 (이게 갖춰지기 전엔 시작하지 않음)
1. 서울아레나 측과의 제휴/파트너십이 구체적 단계로 진입
2. 조감도 등 시각 자료의 사용 권한 확보 (또는 자체 제작 비주얼 준비)
3. SHOWDAY 1.0(로그인, 온보딩, 조건 조합 추천, Supabase 사용자 데이터)이
   실제로 안정화된 이후 — 리소스 분산 방지
