SHOWDAY 관심 아티스트 + 알림 연동 패치

추가/덮어쓰기 파일
1) src/app/artists/page.tsx              [새 폴더/새 페이지]
2) src/components/home/InterestArtistsSection.tsx
3) src/components/layout/Header.tsx
4) src/app/my/page.tsx

핵심 동작
- 상단 '관심 아티스트' 클릭 -> /artists 전용 페이지
- SHOWDAY 데이터 기준 아티스트 TOP 10 표시
- 아티스트 직접 검색 및 관심 등록
- 관심 아티스트의 예정 공연 목록 표시
- 공식 티켓 오픈일/시간 데이터가 있으면 표시
- 공식 오픈시간이 없으면 '공식 오픈일·시간 미확인'으로 표시
- 예매 URL이 있으면 '빠른예매' 버튼 표시
- MY SHOWDAY 알림 설정과 관심 아티스트 페이지 설정을 localStorage 키 showday:alert-prefs:v1 로 공유
- 관심 아티스트 새 공연 / 티켓 오픈 / 내 주변 무료 행사 / 저장조건 새 소식 토글
- 티켓오픈 사전알림: 하루 전 / 1시간 전 / 10분 전

주의
- 현재 이 패치는 '알림 설정값 저장 + 화면 연동'까지입니다.
- 실제 웹푸시/카카오 알림 발송은 별도 발송 서버(스케줄러)와 연결되어야 합니다.
- 공연 데이터에 공식 티켓 오픈 시간이 없는 경우 임의 시간을 만들지 않습니다.
