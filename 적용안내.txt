SHOWDAY 모바일 검색결과 UI 개선

교체 파일:
src/components/home/Hero.tsx

개선 내용:
1. 모바일(767px 이하) 검색 완료 후 큰 검색 패널 자동 접기
2. 검색 완료 후 공연 결과 영역으로 자동 이동
3. 상단에 검색 조건 요약 + '조건 다시보기' 버튼 표시
4. 모바일 검색결과 헤더의 sticky 해제 — 공연 카드가 가려지지 않음
5. 결과 대분류/무료 신청상태/세부분류 버튼을 모바일 가로 스크롤로 변경해 세로 높이 축소
6. PC/태블릿 큰 화면(768px 이상)은 기존 sticky 결과 헤더 유지

적용 방법:
ZIP을 풀어 기존 프로젝트의 같은 경로에 Hero.tsx만 덮어쓰세요.
